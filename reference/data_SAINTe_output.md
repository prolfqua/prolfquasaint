# SAINTexpress example output

Output of a SAINTexpress run, used by the examples of
[`ContrastsSAINTexpress`](https://prolfqua.github.io/prolfquasaint/reference/ContrastsSAINTexpress.md).
Moved here from prolfqua 1.9.0.

## Usage

``` r
data_SAINTe_output
```

## Format

A list of three data frames: \`listFile\` (path of the SAINTexpress
\`list.txt\`), \`list\` (236 interaction scores, 17 columns) and \`out\`
(the console output of the run, one line per row).
