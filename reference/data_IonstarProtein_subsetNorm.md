# IonStar protein-level example data

Median-polish protein abundances of a subset of the IonStar E. coli
spike-in dilution series (PRIDE PXD003881), normalized. Used by the
examples of
[`protein_2localSaint`](https://prolfqua.github.io/prolfquasaint/reference/saintExpress.md).
Moved here from prolfqua 1.9.0.

## Usage

``` r
data_IonstarProtein_subsetNorm
```

## Format

A list with \`data\`, a data frame with 3260 rows (columns
\`protein_Id\`, \`sampleName\`, \`dilution.\`, \`run_Id\`, \`raw.file\`,
\`isotope\`, \`medpolish\`), and \`config\`, its
[`AnalysisConfiguration`](https://wolski.github.io/prolfqua/reference/AnalysisConfiguration.html).

## Source

PRIDE PXD003881
